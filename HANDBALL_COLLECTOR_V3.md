This version keeps the successful V2 SportyBet network extraction and adds page metadata parsing for:

- tournament / league
- kickoff date and time in WAT (Africa/Lagos)
- home and away fallback names

Run:

GitHub Actions -> **Plot207 Handball Collector V3** -> **Run workflow**

- Handball fixture candidates extracted: N
- With kickoff: N/N
- With tournament: N/N
- Complete metadata: N/N
