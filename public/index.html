01Football probabilities use the existing Poisson attack/defence model plus a capped H2H modifier. Recent direct meetings carry more weight, with H2H influence capped so old meetings cannot dominate current form.
02Basketball and ice-hockey percentages are de-margined market-implied probabilities calculated from current SportyBet odds. They are not presented as an independent statistical prediction because this project does not yet have historical basketball/hockey result feeds.
03Add selections from any supported sport to one slip, then press Generate SportyBet Code. The returned code recreates the selected pre-match outcomes on SportyBet while they remain available.
04Value Engine: each auto-pick now compares the selection probability with bookmaker-implied probability (1 ÷ odds), calculates edge and expected value, applies a market-reliability weight, and produces a 0–100 quality score. The Auto Builder uses 1X2, 1UP, GG/NG, Double Chance, Draw No Bet, Over 1.5, Under 4.5 and Asian Handicap 0/±0.25. O/U 2.5 is excluded. DNB and Asian quarter-lines use settlement-aware fair-price probabilities because draws can push or half-settle. Slip probability still assumes independence, so it remains an estimate rather than a guarantee.
