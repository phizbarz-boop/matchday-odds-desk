# Multi-sport Auto Builder

Users can now select any combination of Football, Basketball and Ice Hockey in both the Website and Telegram Auto Builder.

The backend receives an explicit sports array and fetches only those sports. Existing single-sport and All Sports settings are migrated automatically.

Examples:
- Football only
- Football + Basketball
- Basketball + Ice Hockey
- Football + Basketball + Ice Hockey

Today Only, probability filters, red-flag protection, caches, prediction formulas and booking-code creation are unchanged.
