# Over 0.5 Goals Auto Builder

Added **Over 0.5 Goals only** to the Website Auto Builder and Telegram Auto Builder.

- SportyBet market: Over/Under, market ID 18, specifier `total=0.5`
- Model: existing Poisson + capped H2H model
- Website: appears as `Over 0.5 Goals` in Auto Builder bet types
- Telegram: eligible under the existing Telegram probability and red-flag rules
- Under 0.5 is not implemented
- Existing maximum target odds and maximum odds-per-match behavior is preserved
