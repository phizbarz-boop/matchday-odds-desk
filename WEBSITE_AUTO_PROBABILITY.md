# Website Auto Builder probability

The website Auto Builder minimum probability is fully user-controlled.

- A user-entered value from 0 to 95 is passed unchanged (within that range).
- 0 is a valid minimum and is not replaced by the default.
- 55 is used only if the browser/server receives a non-numeric or missing value.
- Telegram's fixed probability thresholds are separate and do not affect website Auto Builder.
- Edge and quality are not website eligibility gates.
- Red-flag sanity protection remains enabled.
