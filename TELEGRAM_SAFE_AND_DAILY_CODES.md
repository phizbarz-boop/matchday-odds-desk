# Telegram SAFE + Today's Codes

## SAFE tickets

Both Telegram SAFE entry points now use only:
- Basketball
- Ice Hockey

This applies to:
- the interactive bot's `Best Picks` / SAFE ticket
- the scheduled `/api/telegram/daily-picks` SAFE slip

Existing SAFE requirements remain:
- minimum leg probability: 90%
- combined odds must land inside 1.30-2.00
- red-flag protection remains enabled
- scheduled daily SAFE fixtures must play today in WAT

Normal non-SAFE Auto Builder sport selection is unchanged.

## Today's Codes

The Telegram main menu now includes `Today’s Codes`.

It displays booking codes generated by the scheduled daily Auto Picks for the current WAT date and does not display the match selections.

Access:
- Free: sees regular daily codes; 1000x and 10000x are hidden/locked.
- Pro: sees all generated daily codes.
- Elite: sees all generated daily codes.

The section does not consume an AI ticket.

Codes are cached in Redis for 48 hours under a WAT-date key. A process-memory fallback is used if Redis is unavailable.


## Updated access
- Free: SAFE + 10x only.
- Pro/Elite: all daily codes.
